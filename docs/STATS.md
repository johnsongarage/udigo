# 사용 통계 설정 방법

통계는 두 가지예요. 둘 다 **새 서버 없이** 돌아가요.

| | 무엇을 아나 | 어디서 보나 |
|---|---|---|
| ① 방문자 통계 (Cloudflare) | 하루 몇 명이 들어왔나, 어디서 왔나(카톡·검색·QR), 폰 기종 | Cloudflare 대시보드 > Web Analytics |
| ② 사용 통계 (Apps Script + 구글 시트) | 매장(폰)마다 **썼냐 안 썼냐**: 처음·마지막 쓴 날, 쓴 날 수 | 구글 시트 "창고여지도 사용 통계" |

앱이 보내는 것은 **무작위 번호와 앱을 쓴 날짜뿐**이에요. 사진, 이름, 메모, 매장 이름은 물론 사진·물건 개수나 검색 횟수도 보내지 않아요.
(로드맵에 필요한 건 "한 달 뒤에도 쓰나"뿐이라, 필요한 것만 모아요)
예시 데이터만 있는 폰은 ②를 보내지 않고, 설정 > **사용 통계 보내기**를 끄면 ①②를 둘 다 안 보내요.

## ② 사용 통계 켜기 (먼저 하기)

1. [script.google.com](https://script.google.com)에서 **AI 구역 찾기에 쓰던 그 프로젝트**를 연다
2. 저장소의 `server/ai-proxy.gs` 내용을 **전부 복사해서 붙여 넣고** 저장
3. 위쪽 함수 고르는 칸에서 **`testStats`** 를 고르고 **[실행]**
   - "권한 필요" 창이 뜨면 → 내 계정 선택 → [고급] → [(프로젝트 이름)(으)로 이동] → **[허용]** (구글 시트를 만들 권한)
   - 아래 실행 로그에 `통계 시트: https://docs.google.com/...` 주소가 나오면 성공 → 그 주소를 즐겨찾기
4. **[배포] → [배포 관리] → 연필(수정) → 버전 "새 버전" → [배포]**
   - ⚠ **새 배포를 만들면 주소가 바뀌어** AI 구역 찾기까지 멈춰요. 꼭 기존 배포를 수정
5. 시트에 생긴 `TEST00` 줄은 지워도 돼요

### 시트 보는 법
- **번호** 탭: 폰 하나에 한 줄. **"매장 메모" 칸에 매장 이름을 직접 적어요**
  - 세팅해 드린 날, 사장님 폰의 설정 > 사용 통계 보내기 옆에 보이는 번호(예: `K7Q2MX`)를 기록표에 적어 두고 → 시트에서 그 번호 줄에 매장 이름을 적기
- **쓴 날** 탭: 받은 그대로 한 줄씩 (번호, 쓴 날)
- 로드맵의 **"계속 사용"** = 번호 탭의 **"마지막 쓴 날"이 최근 2주 안**
- 예전 버전에서 생긴 **날짜별·번호별** 탭은 지워도 돼요

### 알아 둘 것
- 앱을 연 날을 폰에 적어 두었다가, 인터넷이 될 때 보내요. 인터넷 없이 쓴 날도 **그 날짜 그대로** 나중에 보내요(최대 31일)
- 하루 3,000번이 넘으면 그날은 더 받지 않아요(장난 막기)
- 내 폰으로 시험하면 내 번호도 시트에 생겨요 → 내 폰은 설정에서 **사용 통계 보내기를 끄거나**, 매장 메모에 "내 폰"이라고 적어 두기

## ① 방문자 통계 켜기 (Cloudflare Web Analytics, 무료·쿠키 없음)

1. [dash.cloudflare.com](https://dash.cloudflare.com) 가입(무료) → 왼쪽 **Web Analytics** (또는 Analytics & Logs > Web Analytics)
2. **Add a site** → 주소에 `trafficjourney.github.io` → 완료
3. 나오는 코드에서 `"token": "..."` 따옴표 안의 값을 복사
4. `index.html`에서 `const CF_ANALYTICS_TOKEN = '';` 따옴표 안에 붙여 넣고 배포
   (Claude에게 "Cloudflare 토큰 넣어줘: ○○○" 하면 돼요)
5. 하루쯤 지나면 대시보드에 방문자 수가 보여요

- 홈 화면에 설치해서 **인터넷 없이** 쓴 것은 ①에 잡히지 않아요 → 그래서 ②가 따로 있어요
