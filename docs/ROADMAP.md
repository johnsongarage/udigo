# 창고여지도 로드맵 — 더 많은 사람이 쓰게 하려면

> 정리: 2026-10-11 · 비슷한 정리·창고·지도 서비스에서 빌려올 아이디어
> 상태 표시: ⬜ 아직 · 🟨 하는 중 · ✅ 끝

## 지금 있는 것 / 없는 것

- **있음**: 선반 사진 구역 나누기, 물건 적기, 검색(최근·자주 찾는 것), 음성 여러 개 등록, AI 구역 찾기, 인쇄(사진 지도·큰 글씨 목록·점검표), PDF 백업·공유, 업종 샘플, PWA 설치, 테마
- **없음**: 여러 사람이 같이 보기, 수량·유통기한, 바뀐 기록, 여러 사진을 묶는 매장 전체 지도
- **구조상 한계**: 데이터가 폰 안(localStorage·IndexedDB)에만 있고 서버가 없음 → 공유 기능은 저장소가 필요

## 추천 순서

| 단계 | 기능 | 노력 | 효과 | 상태 |
|---|---|---|---|---|
| 1. 지금 바로 | ② QR 라벨 인쇄 양식 | 작음 (서버 없이) | 유입 ↑ | ⬜ |
| 1. 지금 바로 | ③ 업종별 템플릿 페이지 | 작음 | 검색 유입 ↑ | ⬜ |
| 2. 다음 | ① 보기 전용 공유 링크 + 인쇄물 QR | 중간 (저장소 필요) | 입소문 ↑↑ | ⬜ |
| 3. 그다음 | ④ 수량·부족 알림·유통기한 | 중간 | 매일 여는 앱 | ⬜ |
| 3. 그다음 | ⑥ AI가 물건 이름까지 제안 (OCR·비전) | 중간 | 첫 사용 성공률 ↑ | ⬜ |
| 4. 나중 | ⑤ 매장 전체 지도 (평면도 + 사진 핀) | 큼 | 큰 매장 | ⬜ |
| 4. 나중 | ⑦ 바뀐 기록 ("마지막으로 본 자리") | 중간 (①이 먼저) | 팀 사용 | ⬜ |
| 4. 나중 | ⑧ 집·이사용으로 넓히기 | 작음~중간 | 새 시장 | ⬜ |

**제일 먼저 하나만 한다면: ② QR 라벨 인쇄** — 지금 인쇄 코드를 거의 그대로 쓰고, 나중에 ① 공유 링크와 이어지면 바로 입소문 통로가 된다.

## 아이디어 자세히

### ① 같이 보기 링크 + 인쇄물에 QR
- **빌려올 곳**: 구글·네이버 지도 "내 장소 리스트 공유", 노션 링크 공유, Sortly 팀 초대
- 사장님이 링크를 보내면 직원·알바생은 설치·가입 없이 **보기만** 가능
- 인쇄물(사진 지도·점검표) 구석에 QR → 찍으면 그 구역 지도가 열림
- **왜 늘어나나**: 링크 받은 알바생이 자기 매장에서도 씀. 벽에 붙은 인쇄물이 곧 광고
- **주의**: 저장소 필요 → 이미 쓰는 Apps Script(`server/ai-proxy.gs`) 활용 또는 Firebase/Supabase. 처음엔 "읽기 전용 스냅샷"만으로 작게 시작

### ② 상자·선반 QR 라벨
- **빌려올 곳**: Sortly, Homebox, 이사 짐정리 앱(박스마다 QR)
- 구역마다 작은 QR 스티커 인쇄 → 찍으면 "이 상자 안에 뭐가 있는지"
- 인쇄 창에 **"라벨 스티커" 양식 하나 추가**하면 됨 (처음엔 앱 안 구역으로 바로 여는 주소)

### ③ 업종별 템플릿 모음
- **빌려올 곳**: 노션 템플릿 갤러리, 캔바
- 편의점·약국·미용실·꽃집·식당 주방·사무실 비품실 등 업종마다 페이지 하나씩 (지금 `sample*.html` 확장)
- 업종마다 따로 주소 → "편의점 창고 정리" 같은 검색으로 들어오는 길

### ④ 수량·부족 알림·유통기한 (켜고 싶은 사람만)
- **빌려올 곳**: Sortly 재고 부족 알림, 냉장고 관리 앱 유통기한 알림
- 물건에 "수량"·"유통기한" 칸을 선택해서 켬
- 점검표 인쇄와 연결 → "부족한 것 / 주문할 목록" 자동
- **왜 늘어나나**: "가끔 찾는 앱"이 "매일 여는 앱"이 됨

### ⑤ 매장 전체 지도
- **빌려올 곳**: 이케아·홈디포 앱 통로 번호 안내, 카카오맵 실내 지도
- 매장 배치도(손그림 사진이나 간단한 네모 칸)에 선반 사진을 핀으로 꽂기
- 검색하면 "창고 → 왼쪽 선반 → 3번째 칸"처럼 단계별 안내

### ⑥ 사진 찍으면 물건 이름까지 자동
- **빌려올 곳**: 구글 렌즈, Sortly AI 물건 인식
- 지금 AI는 구역만 찾음 → 박스 글씨 OCR, 비전 AI로 물건 이름 후보 제안
- 코드에 이미 "추후 OCR" 확인 목록 자리가 있음 (`index.html` 가져오기 확인 목록)
- **효과**: 사진 한 장으로 지도가 거의 채워짐 → 처음 써 본 사람이 끝까지 감

### ⑦ 바뀐 기록
- **빌려올 곳**: 애플 '나의 찾기' 마지막 위치, 구글 문서 변경 기록
- "우유 → 냉장고 2칸으로 옮김 (10/11, 민수)"
- ① 같이 쓰기가 생긴 뒤에 의미가 커짐

### ⑧ 집·이사용으로 넓히기
- **빌려올 곳**: Sortly 홈, 이사 박스 앱
- 지금 구조 그대로 "집 수납장 / 이사 박스 / 캠핑 장비" 템플릿만 추가
- 이름·첫 화면이 "매장" 중심이라 집용 들어오는 페이지가 따로 있으면 좋음
