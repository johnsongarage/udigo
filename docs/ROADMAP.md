## 0. 방문 준비 (~10/30)

### 안정성 점검 리스트 — 실제 폰에서 하나씩
| # | 점검 | 어떻게 확인 | 안드로이드 | 아이폰 |
|---|---|---|---|---|
| ① | **데이터가 사라지지 않음** | 사진 5장·물건 50개 넣고 → 앱 껐다 켜기, 폰 재시작, 1주일 안 열기 | ⬜ | ⬜ |
| ② | **인터넷 없이 쓰기** | 비행기 모드로 앱 열기·검색·물건 추가 | ⬜ | ⬜ |
| ③ | PDF 인쇄·백업 | 인쇄 3종 PDF 받기, 백업 보내기 → 다른 폰에서 불러오기 | ⬜ | ⬜ |
| ④ | 홈 화면 설치 | 설치 후 아이콘으로 열기, 주소창 없이 열리는지 | ⬜ | ⬜ |
| ⑤ | 사진 많을 때 | 사진 20장 넘게 넣고 속도·저장 공간 경고 | ⬜ | ⬜ |
| ⑥ | 오래된 폰 | 2~3년 된 폰, 큰 글씨 설정에서 화면 깨짐 | ⬜ | ⬜ |

> ⚠ **아이폰 주의**: 사파리는 브라우저에서만 쓰고 한동안 안 열면 저장한 데이터를 지울 수 있다. **홈 화면에 설치해서 쓰게 하는 것**을 세팅 순서에 꼭 넣고, 세팅이 끝나면 백업 파일을 사장님 카톡으로 한 번 보내 둔다.

### 그 밖에
- ⬜ 시연용 샘플: 방문할 업종(카페·편의점 등) 1~2개를 실제 같은 사진으로
- ⬜ 기록표 양식 (아래 "기록표")
- ⬜ 세팅 순서표: 설치 → 사진 → 구역 → 물건 → 검색 시연 → 백업 보내기 (목표 30분 안)
- ⬜ 카톡 채널 이름을 "창고여지도"로 바꾸기, 공유 미리보기 캐시 지우기
- ⬜ 무료 방문 신청(구글 폼) 들어온 곳 일정 잡기 — 앱 안 안내는 10/31 지나면 자동으로 숨겨짐

## 1. 현장 검증 (10/31~11/30)

- 매장 10곳 세팅. **업종을 섞기** (카페만 10곳이면 결과가 한쪽으로 쏠림)
- **찾는 시간 재기**: 세팅 전에 직원에게 물건 3개 찾게 하고 시간 재기 → 1~2주 뒤 같은 물건으로 다시 재기
- **세팅에 걸린 시간 재기** → 4단계 세팅 대행 가격 정할 때 씀
- "가장 불편한 것"은 한 가지만 묻고 사장님 말 그대로 적기
- 나온 문제는 **매주 한 번 묶어서 고치기** (금요일 배포 등 요일 정하기). 고친 내용은 카톡 채널로 알림

### 기록표 (매장마다 한 줄)
| 매장 | 업종 | 세팅일 | 세팅 시간 | 찾는 시간 전→후 | 사진·물건 수 | 가장 불편한 것 | 직원 수 | 1주 뒤 | 한 달 뒤 | 낼 의향(얼마) |
|---|---|---|---|---|---|---|---|---|---|---|

## 2. 한 달 뒤 확인 + 결정 (12월)

- **"계속 사용"의 뜻을 미리 정해 두기**: 최근 2주 안에 검색했거나 물건을 고친 적이 있음 (방문·전화로 확인)
- 돈 낼 의향은 "쓰시겠어요?" 대신 **가격을 넣어 묻기**: "월 ○○원이면 계속 쓰시겠어요?" (두세 가격으로)
- 답을 모아 **첫 유료 기능 하나**만 고르기. 후보:
  - 직원과 같이 쓰기 (가장 유력, 서버 필요)
  - 엑셀로 한 번에 등록
  - 수량·부족 알림·유통기한
  - 사진 찍으면 물건 이름까지 자동 (AI)
- 같이 쓰기가 뽑힐 가능성이 크므로 **12월에 서버 저장 방식 미리 시험** (Apps Script / Firebase / Supabase 중 하나로 작게)

## 3. 첫 유료 기능 (1~2월)

- 1위 불편 해결 기능 만들기 — 기존 매장에서 먼저 써 보게
- **돈 받기 전에 필요한 것**
  - ⬜ 사업자등록 + 통신판매업 신고
  - ⬜ 결제 (토스페이먼츠 등 정기결제)
  - ⬜ 이용약관 · 개인정보처리방침 — **데이터가 서버로 올라가는 순간부터 필요**
  - ⬜ 폰 안 데이터를 서버로 옮기기 (기존 매장 데이터 안 잃게)
- 초기 10곳에는 **평생 할인** 안내 (예: 정가의 50%)

## 4. 정식 출시 (3월~)

- "베타" 떼기 조건: 결제 3곳 이상 + 한 달 동안 데이터 사라짐 신고 없음
- 요금제 공개: 무료(한 매장·혼자) / 유료(같이 쓰기 등)
- 세팅 대행: 1단계에서 잰 세팅 시간을 바탕으로 가격
- 들어오는 길 늘리기
  - 카톡 채널, 기존 매장 소개 (소개하면 한 달 무료 등)
  - **업종별 소개 페이지** ("편의점 창고 정리" 같은 검색으로 들어오게)
  - 인쇄물 구석에 앱 주소·QR → 벽에 붙은 종이가 광고

## 5. 확장 (이후)

- 여러 매장 관리 (사장님 한 명이 매장 여러 곳)
- 프랜차이즈 시범: 본사 템플릿 → 매장마다 복사
- 같이 쓰기 위에 **QR 라벨**: 상자·선반에 붙이고 찍으면 그 구역이 열림
- 바뀐 기록 ("우유 → 냉장고 2칸으로 옮김, 10/11, 민수")
- 매장 전체 지도 (배치도에 선반 사진 핀)
- 필요하면 플레이스토어 앱 (지금 PWA를 감싸서)

## 지켜야 할 원칙

1. **현장 반응이 먼저, 기능은 나중.** 매장에서 나온 불편이 아니면 만들지 않는다. 아래 "아이디어 창고"는 후보일 뿐이다.
2. **데이터를 잃지 않는 것이 1순위.** 데이터가 한 번 날아간 매장은 다시 안 쓴다. 새 기능보다 저장·백업 문제를 먼저 고친다.
3. **기준을 못 넘으면 다음 단계로 가지 않는다.** 기준은 단계 시작 전에 정하고, 결과를 본 뒤에 바꾸지 않는다.
4. **한 번에 하나.** 유료 기능도 하나부터. 고치는 것도 매주 한 묶음.
5. **사장님 말로.** 화면 글, 안내, 요금제 이름은 현장에서 들은 말을 쓴다.
6. **기본 기능은 계속 무료.** 혼자 쓰는 한 매장 지도는 무료로 둬서 소개가 끊기지 않게 한다.

## 위험과 대비

| 위험 | 대비 |
|---|---|
| 아이폰에서 데이터가 지워짐 | 홈 화면 설치 필수, 세팅 끝에 백업 보내기, 1단계 동안 주마다 확인 |
| 폰 분실·교체 | 백업 파일 안내, 3단계 서버 저장으로 근본 해결 |
| 10곳이 한 업종에 쏠림 | 모집할 때 업종 섞기 |
| 같이 쓰기 개발이 길어짐 | 12월에 미리 시험, 처음엔 "보기 전용 링크"로 작게 |
| 혼자 하기에 일이 많음 | 매주 고치기 요일 고정, 기록표 한 장으로 관리 |
