# udigo → objetdo 옮김 판

오브젯도 주소가 `johnsongarage.github.io/udigo/`에서 `johnsongarage.github.io/objetdo/`로 바뀌었다 (2026-11).

- 브라우저로 들어오면 바로 새 주소로 넘긴다 (`?`·`#` 그대로, 같은 사이트라 지도 데이터도 그대로).
- 홈 화면에 설치한 앱으로 들어오면 넘기지 않고 이 앱을 그대로 열고, 위쪽 띠로 옮기는 법을 안내한다 (아이폰 홈 화면 앱은 사파리와 저장소가 따로라서).
- 다른 주소(`price/`·`start/`·`qr/` 등)는 `404.html`이 같은 자리의 `/objetdo/`로 넘긴다.
- 이 저장소는 고치지 않는다. 앱은 `johnsongarage/objetdo`에서 고친다.
